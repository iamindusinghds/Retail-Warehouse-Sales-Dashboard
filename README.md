# Retail & Warehouse Sales Dashboard

## Project Overview
This project analyzes retail and warehouse sales data using Power BI. The dashboard provides insights into sales trends, supplier performance, and item category distribution.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features
- KPI Cards
- Monthly Sales Trend Analysis
- Supplier Performance Analysis
- Item Type Sales Comparison
- Interactive Filters/Slicers

## Key Insights
- Certain item categories generated significantly higher sales than others.
- Monthly sales trends fluctuated across the year.
- Top suppliers contributed major share of total revenue.

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Dashboard Design
- Business Analytics
- Data Visualization
